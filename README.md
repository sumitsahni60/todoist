## 🌐 Timezone Converter

A standalone Timezone Converter tool is built into this app.

### How to use it

1. Start the development server:
   ```bash
   npm start
   ```
2. Open your browser and go to:
   ```
   http://localhost:3000/timezone
   ```

### Features
- Pick any **date & time** with a datetime picker.
- Choose a **source timezone** (e.g. UTC, America/New_York, Asia/Kolkata, …).
- Choose a **target timezone** to convert to.
- Hit **⇅ Swap** to instantly reverse the conversion direction.
- The converted time updates live as you change any field.

You can also reach the converter from the main app by clicking the 🔗 link icon in the top header.
